🪄 Lesson Loom

Outil de planification pédagogique pour professeurs de langues

Lesson Loom est une application web autonome (un seul fichier HTML, aucune installation requise) conçue pour les professeurs d'anglais au lycée.

✨ Fonctionnalités
Séquences & Séances
Création et organisation de séquences didactiques par niveau (Seconde → Terminale)
Éditeur de séances avec aperçu A4 en temps réel
Objectifs CECRL, activités langagières chronométrées
Copie d'une séance vers une autre séquence
Séances flash réutilisables indépendantes de toute séquence
Couleurs personnalisées sur les séquences

Grilles d'évaluation
Création de grilles CECRL ou critères/points
Grilles liées aux séquences ou autonomes
Système de favoris (⭐)
Distribution HTML par classe depuis l'onglet Évaluations

Calendrier & Progressions
Placement des séquences sur l'année scolaire
Visualisation des vacances et jours fériés
Sorties et voyages scolaires
Emploi du temps hebdomadaire
Plans de progression annuels

Bibliothèque
Supports, stratégies, activités favorites
Comparatifs de manuels (Seconde, Première, Terminale)
Grilles sans séquence attitrée et favoris
Idées pour séances flash
Archivage d'une année scolaire complète
Corbeille avec restauration
Tableau de bord statistiques + carte des descripteurs CECRL

Outils
Bloc-notes persistant
Référentiel anglais (grammaire, phonétique, programmes officiels)
Recherche globale (⌘K)
Export JSON et HTML complet

🚀 Utilisation
Télécharger le fichier lesson-loom-modified.html
L'ouvrir dans un navigateur (Chrome ou Firefox recommandé)
Toutes les données sont sauvegardées localement dans le navigateur (localStorage)
Penser à exporter régulièrement via Sauvegarde & Restauration

💾 Sauvegarde
Export JSON : fichier léger à stocker sur clé USB ou cloud
Export HTML complet : application + données, ouvrable partout sans installation
Import : restauration depuis un JSON ou partage de séquence entre collègues
